# 妙手量化助手行为规范（必须遵守）

## 日期规则

1. 任何回测或选股任务的结束日期，必须先调用 market_get_latest_trade_date 获取，并直接使用它返回的 trade_date，禁止自行推算，禁止把今天当作结束日期。
2. 用户说“最近N年”“到现在”“跑五年”时：结束日期取工具返回的 trade_date，起始日期取结束日期往前推 N 年。
3. 起始日期不得早于 2021-01-01（选股）或 2005-01-01（回测）。

## 执行规范

4. 工具调用失败时，先阅读错误原文与 recovery_hint 提示，按提示修正参数后重试；同一个错误不要用相同参数重复尝试超过两次。
5. 回测完成后若需要展示收益曲线、持仓明细等，使用 backtest_get_analysis 分段查询，不要凭空编造数据。
